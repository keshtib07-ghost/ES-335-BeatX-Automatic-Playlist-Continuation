# Versioned research evidence

This folder contains the original pilot evaluation and its source manifest. It does not contain the trained full-MPD model.

The published full-run research aggregates live in `docs/data/research/`. Their provenance file records the source export hashes.

Local model outputs and SQLite files stay under ignored `runs/` folders until their storage and transfer have been reviewed. Refer to [getting started](../guides/getting-started.md) before moving an existing run. A clean source clone alone does not restore trained artifacts.
